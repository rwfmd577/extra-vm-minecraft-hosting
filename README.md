**Vanilla servers (no mods, no plugins):**
- 2GB — around 10 players
- 3GB — around 15 players

**Plugin servers (PaperMC, Spigot, Purpur):**
- 4GB — light plugins, around 20 players
- 6GB — moderate plugins, around 30 players
- 8GB — heavy plugin setups, around 40 players

**Modpack servers (Forge, Fabric, large packs):**
- 6GB — light modpacks (50–100 mods)
- 8GB — medium modpacks (100–200 mods)
- 10–12GB — heavy modpacks like All The Mods, RLCraft, or Feed The Beast (200+ mods)

The honest takeaway: if you're running a small SMP for friends, 2–3GB is plenty. If you're running a public Paper server with 30 plugins, plan for 6GB. If you want to throw All The Mods 9 at a server, start at 10GB and be ready to upgrade.

ExtraVM explicitly says you can start small and upgrade later by opening a support ticket — your world data and files are preserved during the change. That's a useful safety net: you don't have to guess perfectly on day one.

## Java Edition vs Bedrock Edition: Which One Do You Need?

ExtraVM supports both, and the choice depends on who's playing.

**Java Edition** is the original PC version with the giant modding community. If you want Forge or Fabric modpacks, PaperMC plugins, Spigot, Purpur, or anything from CurseForge / Modrinth / Feed The Beast, this is the one. ExtraVM's Java hosting includes one-click modpack installation from those platforms — you don't have to manually upload files via SFTP unless you want to.

**Bedrock Edition** is the cross-platform version that runs on Windows 10/11, Xbox, PlayStation, Nintendo Switch, iOS, and Android. If your friend group is split across PC and console, Bedrock lets everyone connect to the same world. It doesn't have the same modding ecosystem as Java, but for casual shared worlds it's the right pick.

You can also run a Geyser-style setup to bridge Java and Bedrock players, though that adds overhead and may push you up a RAM tier.
